# Third-party notices

## Better Icons

The icon selection workflow uses [Better Icons](https://github.com/better-auth/better-icons), an MIT-licensed Iconify search and retrieval tool. The application renders its own native egui vector paths so icon color, hover state, keyboard focus and display scaling remain controlled by the desktop UI.

## Tabler Icons

The outline icon style is based on the Tabler icon collection, retrieved through the Better Icons workflow. Tabler Icons are MIT licensed: <https://github.com/tabler/tabler-icons>.
